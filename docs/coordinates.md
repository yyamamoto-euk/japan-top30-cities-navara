# 柱の座標の決め方

`data/entities.csv` の `lon`・`lat`・`coord_basis` の根拠。

## 基本：今の市役所の位置（73本）

- 国土数値情報「市町村役場等及び公的集会施設」P34（2014年）の本庁の位置を使った
- 使用許諾条件は**非商用**。画面に出典を表示する必要がある。商用にするときは座標を入れ直す
- 埋め方：`pnpm data:fill-coords`（`scripts/fill-entity-coords.ts`）。「今の市の名前＋役所」の本庁を探し、`coord_basis` が「要手入力」の柱だけを埋める
- 原本：`data/raw/P34/`。出典の行：`data/sources.csv` の `P34_KSJ`
- 1886年にしか出てこない柱は、今の市の役所を使った（高田 → 上越市役所、宇治山田 → 伊勢市役所 など）

## 個別に決めた3本（2026-11-22、yyamaの指定）

### tokyo（東京｜東京市｜特別区部）

- 座標：35.676940, 139.764170
- 根拠：旧東京府庁舎跡。1898年から東京市役所が同居していた。今の東京国際フォーラム
- 座標の取り方：東京国際フォーラムの代表点（Wikipedia「Tokyo International Forum」）
- 経緯
  - 東京市は1889年にできたが、市制特例で市役所は置かれず、府が代行した
  - 1898年に特例が廃止され、府庁舎の中に東京市庁舎が開かれた
  - 府庁舎は都庁舎を経て、今の東京国際フォーラムになった
- 1894年より前の府庁舎は内幸町（今の千代田区立内幸町ホール付近）にあった。全国を俯瞰する画面では差が見えないので考慮しない
- 全年次この1点で固定する。2025年の特別区部も、新宿の都庁ではなくこの点
- 出典：このまちアーカイブス 日比谷（smtrc.jp） https://smtrc.jp/town-archives/city/hibiya/p04.html?id=a02

### yahata（八幡）

- 座標：33.863610, 130.811940
- 根拠：旧八幡市庁舎跡（今の八幡東区役所付近）
- 八幡東区役所の正面入口付近の石垣や階段に旧八幡市庁舎の面影が残り、敷地内に旧八幡市章碑がある
  - 出典：北九州市 八幡東区 https://www.city.kitakyushu.lg.jp/yahatahigashi/file_0008.html
- 座標の取り方：八幡東区の代表点（Wikipedia「Yahatahigashi-ku, Kitakyūshū」）
- **要確認**：この点が区役所の位置そのものか。1925年当時の市役所が同じ場所か
- 合併：北九州市へ 1963年（Wikipedia「Yahata, Fukuoka」、SPEC.md）

### shuri（首里）

- 座標：26.217031, 127.719475
- 根拠：首里城（Wikipedia「Shuri Castle」）
- 旧首里市役所の場所が未確認のため、城を採用した
- 合併：那覇市へ 1954年（Wikipedia「Shuri, Okinawa」）

## T2 で確認すること

- 首里（首里城）と那覇（今の那覇市役所）の柱は、4kmほどしか離れていない（概算）
- 1886年など、両方の柱が同時に出る年がある。日本全体の俯瞰では、柱の幅によっては重なるかもしれない
- T2 の完了報告に次の2つを付ける
  - 那覇・首里付近を拡大して見るためのカメラ位置（一時的なものでよい）
  - 重なった場合の対処案（2つまで）
- 重なりはyyamaが見て確認する

## T3 で確認すること（1925年の東京まわり）

- 1925年は、東京の柱のまわりに町の柱が固まる。東京の柱からの距離（概算）：渋谷町 6km、西巣鴨町 8km、平塚町 9km、滝野川町 9km（滝野川町は 2026-11-22 に座標を替える前の値）
- 柱の幅は20km なので、layout.ts が自動で離している。そのため町の柱は、本当の位置から17〜34kmずれて描かれる（2026-11-22、滝野川町の座標を西ケ原に替える前の座標で計算。今は1925年に町を東京の柱に積むので、町の柱は描かれない）
  - 東京の柱から描かれた位置までの距離：渋谷町 40km、西巣鴨町 35km、滝野川町 25km、平塚町 24km。川崎も 17km → 24km
  - 座標を変える前（今の区役所の位置）は、渋谷町 24km、西巣鴨町 39km、滝野川町 36km、平塚町 25km だった。押し合いの結果なので、座標が少し変わるだけで、どの柱がどちらへ押されるかが変わる
- 拡大して見るカメラ：開発サーバーの URL に `?year=1925&camera=tokyo` を付けて開く（frames.ts の DEBUG_CAMERAS.tokyo）
- 対処案として、A（首都圏に寄るコマを足す）と B（町を東京の柱に積む）を出した

### 決めたこと（2026-11-22、yyama）

- **1925年は、町を東京の柱の上に同じ色で積み、1本で見せる**（B を色を変えずに）。東京という括りで理解しやすいため。A はやめた
- 積む町は、今のデータにある4町だけ（渋谷町・西巣鴨町・滝野川町・平塚町）。1932年に入った82町村すべてではない
- 積んだ町は 1925年に別の柱として立たないので、柱を離す計算（layout.ts）からも外した。上の「17〜34kmずれる」は、もう起きない
- 中身は SPEC.md の章立て、作りは src/stack.ts と frames.ts の stackInto
