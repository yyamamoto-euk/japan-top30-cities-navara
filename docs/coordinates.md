# 柱の座標の決め方

`data/entities.csv` の `lon`・`lat`・`coord_basis` の根拠。

## 基本：今の市役所の位置（85本、2026-11-22）

- **OpenStreetMap の市役所の点（58本）**：`amenity=townhall` で、名前が「今の市の名前＋役所」（横浜市は「横浜市市庁舎」、秋田市は「秋田市庁舎」、金沢市は「金沢市役所 第二本庁舎」）の点。建物は中心点。原本は `data/raw/osm/townhall-japan.json`（`pnpm data:fetch-osm`、sources.csv の OSM_TOWNHALL）
  - 国土数値情報 P02（公共施設、2006年）から OpenStreetMap に取り込まれた点（タグ source に KSJ2、source_ref に KsjTmplt-P02、note に National-Land Numerical Information を含む点）は使わない
  - 利用条件：Open Database License（ODbL）1.0。柱の座標（entities.csv の lon・lat）と、それを含む public/data/cities.json は ODbL で、出典「© OpenStreetMap contributors」（https://www.openstreetmap.org/copyright）が要る
- **電子国土基本図（地名情報）（27本）**：OpenStreetMap に P02 由来でない点が無い市（名古屋市・福岡市・千葉市など）は、地理院地図の地名検索で「○○市役所」と名前が完全に一致する点。原本は `data/raw/gsi/townhall-search.json`（sources.csv の GSI_TOWNHALL_SEARCH）
  - 出典の書き方：「電子国土基本図（地名情報）（国土地理院）をもとに作成」。取り方として「地理院地図の地名検索で取得」を添える（entities.csv の coord_basis、README、画面のⓘ）
  - 利用条件：国土地理院コンテンツ利用規約（公共データ利用規約 第1.0版。出典を書けば商用も可）。くわしくは下の「地名検索で取った27本について」
- 大宮は今のさいたま市大宮区役所、小倉は今の北九州市役所、布施は今の東大阪市役所の点（旧市役所の位置は未確認）
- 1886年にしか出てこない柱は、今の市の役所を使った（高田 → 上越市役所、宇治山田 → 伊勢市役所 など）
- 埋め方：`pnpm data:fetch-osm` → `pnpm data:build` → `pnpm data:check-osm`（照合表 `data/check/coords-osm.md`）→ `pnpm data:fill-coords`。探し方は `scripts/lib/townhall.ts`。手で決めた柱（下の節）は触らない

### 地名検索で取った27本について（2026-11-22 調べたこと）

- 地名検索 API（`msearch.gsi.go.jp/address-search/AddressSearch`）そのものの利用規約のページは無い。地理院地図の公式リポジトリの Issue（https://github.com/gsi-cyberjapan/gsimaps/issues/29 ）で、国土地理院が「主に地理院地図からの利用を想定、長期的な提供は保証しない、仕様は予告なく変わる」「住所の検索には東京大学 CSIS のシンプルジオコーディングを使っている」と答えている
- 27本の市役所の点は、応答の dataSource が "3"（地理院地図のソース js/gsimaps.js では「居住地名以外」）。国土地理院は電子国土基本図（地名情報）を地名検索のデータに使っていて、地名情報には公共施設が含まれる（https://www.gsi.go.jp/kibanjoho/kibanjoho40025.html ）。そのため27本は電子国土基本図（地名情報）の公共施設とみられる
- 国土地理院コンテンツ利用規約（https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html ）：加工して使うときは、出典とは別に加工したことを書き、国土地理院が作ったように見せない。そのため「をもとに作成」と書く
- 住所で引いた点は CSIS のサービスの結果なので、国土地理院の規約ではなく CSIS 側の条件になる。その条件のページは見つかっていない。そのため、住所で引いた点は使わない。門司・西巣鴨町・滝野川町・平塚町は、OpenStreetMap の点などに替えた（2026-11-22、下の「仮の座標」の節）
- **未確認**：27本が地名情報の公共施設であること（応答に資料名が無い）
- **未確認**：測量法の承認。国土地理院の Q&A（https://www.gsi.go.jp/LAW/2930-qa.html ）では、複製しない場合は承認不要とされている。27点の座標を取り出すことが複製にあたらないかは、原文からは判断できない

- 2026-11-22 までは、国土数値情報 市町村役場等及び公的集会施設データ（P34、2014年）の点を使っていた。使用許諾条件が非商用なので入れ替えた。前の座標からのずれは、大きいもので鳥取市 1,432m、横浜市 805m、大宮 540m（どれも P34 の2014年より後に庁舎が移ったとみられる）。ほかは 340m 以内

## 描く位置のずれ（2026-11-22）

柱の幅は10km（2026-11-22 に 20km から半分にした）あるので、近い柱どうしは重ならないよう、画面に描く位置をずらしている（src/layout.ts。データの座標は変えない）。ずらし方は全年まとめて一度だけ決めるので、年を送っても柱は横に動かない。

- 測り方：`pnpm data:layout-shift`（scripts/measure-layout.ts）。画面と同じ計算で、描く位置と本当の位置（entities.csv の座標）の差を測る
- 1925年に東京の柱に積む町（渋谷町・西巣鴨町・滝野川町・平塚町）は、その年は描かないので除いた

- 柱の幅が20km（すき間 3km）だったときは、45本をずらし、10km 以上ずれる柱が22本、いちばん大きいのは松戸市の 34.1km だった

## T3 で確認すること（1925年の東京まわり）

- 1925年は、東京の柱のまわりに町の柱が固まる。東京の柱からの距離（概算）：渋谷町 6km、西巣鴨町 8km、平塚町 9km、滝野川町 9km（滝野川町は 2026-11-22 に座標を替える前の値）
- 柱の幅は20km（当時。今は10km）なので、layout.ts が自動で離している。そのため町の柱は、本当の位置から17〜34kmずれて描かれる（2026-11-22、滝野川町の座標を西ケ原に替える前の座標で計算。今は1925年に町を東京の柱に積むので、町の柱は描かれない）
  - 東京の柱から描かれた位置までの距離：渋谷町 40km、西巣鴨町 35km、滝野川町 25km、平塚町 24km。川崎も 17km → 24km
  - 座標を変える前（今の区役所の位置）は、渋谷町 24km、西巣鴨町 39km、滝野川町 36km、平塚町 25km だった。押し合いの結果なので、座標が少し変わるだけで、どの柱がどちらへ押されるかが変わる
- 拡大して見るカメラ：開発サーバーの URL に `?year=1925&camera=tokyo` を付けて開く（frames.ts の DEBUG_CAMERAS.tokyo）
- 対処案として、A（首都圏に寄るコマを足す）と B（町を東京の柱に積む）を出した

### 決めたこと（2026-11-22、yyama）

- **1925年は、町を東京の柱の上に同じ色で積み、1本で見せる**（B を色を変えずに）。東京という括りで理解しやすいため。A はやめた
- 積む町は、今のデータにある4町だけ（渋谷町・西巣鴨町・滝野川町・平塚町）。1932年に入った82町村すべてではない
- 積んだ町は 1925年に別の柱として立たないので、柱を離す計算（layout.ts）からも外した。上の「17〜34kmずれる」は、もう起きない
- 中身は SPEC.md の章立て、作りは src/stack.ts と frames.ts の stackInto

## P34 を入れ替えたときに調べた候補（2026-11-22）

**結果**：候補2（OpenStreetMap の市役所の点）にした。OpenStreetMap に P02 由来でない点が無い27市は、国土地理院の地名検索の点にした（上の「基本」の節）。下は入れ替える前に調べた記録

柱の座標と自治体コード（当時の entities.csv の lon・lat・current_code）の多く（coord_basis が「P34」で始まる82本）は、国土数値情報 市町村役場等及び公的集会施設データ（P34、2014年）から取っている。P34 の使用許諾条件は「非商用」で、元のデータの複製物を再配布できない。リポジトリを eukarya-biz に移すので、商用でも使えて、加工したものを公開してよいデータに入れ替える候補を2つ調べた。どれにするかは yyama が決める。

- 対象外（入れ替えても残る）：手で決めた座標。東京（旧東京府庁舎跡）、八幡、首里、門司、渋谷町、西巣鴨町、滝野川町、平塚町、大宮、小倉、布施。このうち大宮・小倉・布施は P34 の点を使っているので、入れ替えるなら同じ候補で取り直す
- ずれは、合併していない柱で、今の座標（P34 の役所の点）との距離を測った。柱の幅は20km

### 候補1：国土数値情報 行政区域データ（N03）の市区町村の形から、代表点を作る

- 使うもの：国土数値情報 行政区域データ（N03）。手元にある2025年版（data/raw/N03/、git に入れていない）。最新は2026年版
- 利用条件（原文で確かめた）
  - データのページの「このデータの使用許諾条件」：「オープンデータ（CC_BY_4.0）」 https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html
  - 国土数値情報ダウンロードサイトコンテンツ利用規約（政府標準利用規約準拠版）：「商用利用も可能です。」 https://nlftp.mlit.go.jp/ksj/other/agreement_01.html
  - 加工したときの出典の書き方（同じ規約の例）：「国土数値情報（行政区域データ）」（国土交通省）（ページの URL）を加工して作成
  - 未確認：データのページの原典の欄にある「測量法に基づく国土地理院長承認（複製）」について、使う側に手続きが要るか
- 位置：形の内側の代表点（mapshaper の `-points inner`）。**役所の位置ではない**
- コード：全国地方公共団体コード（N03_007、5桁）。ただし政令市は区ごとのコードしか無いので、市のコード（例：横浜市 14100）は別に決める必要がある（今回の試しでは、政令市20市すべてで区のコードになった）。特別区部は23区をまとめて作る
- 入れ替えの手間：data/raw/N03 は寄り道の章で使っていた（scripts/build-prefectures.ts）ので、取得と展開の手順はある。代表点を作るスクリプトを足し、scripts/fill-entity-coords.ts を P34 の代わりにそれを読むよう直す。政令市のコードの表を足す
- ずれ（今の座標から。83本）：中央値 5.5km、90% が 14.4km 以内、最大 39.6km（浜松市）。5km以上が47本（浜松市 39.6km、下関市 25.1km、大津市 19.3km、函館市 17.1km、相模原市 16.3km など）。市域が広いほど、柱が街の中心から離れる

### 候補2：OpenStreetMap の「○○市役所」の点を使う

- 使うもの：OpenStreetMap の `amenity=townhall` で、名前が「○○市役所」の点。Overpass API で取得（2026-11-22 の時点で日本に797件）
- 利用条件（原文で確かめた）
  - Open Database License（ODbL）1.0。https://www.openstreetmap.org/copyright に、改変・加工したデータについて "you may distribute the result only under the same license" とある
  - 商用利用はできる。ただし、加工したデータ（entities.csv の座標）を公開するときは、その部分を ODbL で公開する（同じライセンスを引き継ぐ）必要がある。出典「© OpenStreetMap contributors」と ODbL へのリンクが要る
  - 797件のうち約300件は、タグ `source=KSJ2`（国土数値情報 公共施設データ P02、2006年）から OpenStreetMap に取り込まれた点。OpenStreetMap 上では ODbL で配布されているが、取り込みのときの許諾の中身は未確認
- 位置：役所の建物の点（今の座標とほぼ同じ）
- コード：**無い**（市町村コードのタグが付いた点は0件）。コードは候補1の N03 の形に点を重ねて取るか、総務省の全国地方公共団体コードの一覧から名前で引く（一覧の利用条件は未確認）
- 入れ替えの手間：Overpass API から取得して、都市名と今の座標に近い点で照らし合わせるスクリプトを足す。名前が「○○市役所」と完全に一致しない11本（横浜市、名古屋市、鹿児島市、市川市、和歌山市、秋田市、福井市、徳島市、佐賀市、青森市、豊橋市）は、別の名前（「横浜市庁舎」など）で探すか、手で決める
- ずれ（今の座標から。見つかった71本）：中央値 20m、90% が 70m 以内、最大 1.4km（鳥取市）
